# My Portfolio – Celia Herrero

Este proyecto consiste en un **portfolio web personal** cuyo objetivo es darme a conocer como diseñadora gráfica e ilustradora, mostrando una selección de mis trabajos mediante una estética propia, dinámica y visual.

Se trata de un **proyecto académico**, desarrollado como parte de una asignatura, pero pensado como una **base escalable** que podrá evolucionar en el futuro a medida que aumente mi nivel de programación.

---

## 🎯 Objetivo del proyecto

- Presentar mi trabajo de forma clara y visual  
- Desarrollar una identidad personal a nivel gráfico y digital  
- Aplicar conocimientos básicos de desarrollo web y intentar aprender cosas mientras realizo el proyecto
- Crear una base reutilizable para un portfolio profesional futuro  

---

## 🖥️ Tecnologías utilizadas

El proyecto ha sido desarrollado con tecnologías web básicas:

- **HTML5** – estructura del contenido  
- **CSS3** – diseño visual y estilos  
- **JavaScript** – interacciones y dinamismo  

> No se han utilizado frameworks externos, con el objetivo de afianzar los fundamentos del desarrollo web. :contentReference[oaicite:0]{index=0}

---

## ▶️ Uso del proyecto

Este proyecto es una **web estática**.

Para visualizarlo:

1. Descargar o clonar el repositorio  
2. Abrir el archivo `index.html` en cualquier navegador web  

No requiere instalación ni dependencias adicionales.

---

## 📁 Estructura del proyecto

- `/assets` → imágenes y recursos visuales  
- `/css` → hojas de estilo  
- `/js` → scripts de JavaScript  
- `index.html` → página principal  
 

---

## 🚀 Estado del proyecto

El proyecto se encuentra en una **fase inicial**, pero funcional.  
Está planteado como una base que podrá ampliarse en el futuro con:

- Mejor organización del código  
- Nuevas secciones  
- Animaciones más avanzadas y dinamicas
